# Project Instructions

Before creating or altering UI, CSS, layout, or visual component styling, consult the Design System section of `docs/product-blueprint.md`.

Treat it as the project design direction, but verify CSS tokens against the existing theme files before use. Do not invent one-off CSS variables in component styles. If the guide references a missing token, either use the closest existing project token or add/update theme tokens deliberately.

Doc map: `docs/README.md`. Current status: `PROJECT_STATUS.md`. Active roadmap and work slices: `docs/road-to-market.md`.
